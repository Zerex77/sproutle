“Who Said That? ← Zach Box

Two answers. One prompt. Pick a side.

A party game for 3 to 10 people. Everyone writes funny answers to prompts, then the answers go head to head and the room votes for the best one. Names only come out after the vote.

  1. 1Everyone gets two prompts. Each prompt also goes to one other player, so you're always up against someone.
  2. 2The TV shows each prompt with both answers, no names. Everyone else votes for the funnier one.
  3. 3Every vote is points. Win every vote for a Clean Sweep. Two rounds, then a free-for-all final where everyone answers the same prompt.
